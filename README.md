# DFAR

Department of Fisheries and Aquatic Resources (DFAR) Management System.

## Running Locally

To run the application locally:
1. Ensure MySQL is running and the `dfar_ms` database is available.
2. Start the servers:
   - **macOS / Linux**:
     ```bash
     ./run_local.sh
     ```
     To stop: `./stop_local.sh`
   - **Windows**:
     Double click `run_local.bat` or run:
     ```cmd
     run_local.bat
     ```
     To stop: `stop_local.bat`
3. Access:
   - **Backend**: http://localhost:8080
   - **Frontend**: http://localhost:8081
